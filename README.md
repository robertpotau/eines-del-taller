# Eines del taller

Joc educatiu en català per aprendre les **39 eines del taller de Tecnologia** (1r ESO): reconèixer la foto, el nom i la **família** de cada eina. Estudia amb Catàleg i Flashcards i practica o competeix amb 8 jocs per a 1 a 6 jugadors (Classifica, Memory, Uneix, Esquema → eina, Escala d'eines, Ronda ràpida, Quina eina és?, Per a què serveix?).

**Juga-hi:** https://robertpotau.github.io/games/eines-del-taller/index.html
